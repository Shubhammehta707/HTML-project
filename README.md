# 🍦 Freeze – Frozen Yogurt Shop Website

## 📌 About the Project

**Freeze** is a simple and attractive frozen yogurt shop website developed using HTML and CSS. The website showcases a frozen yogurt brand with a clean layout, colorful design, and easy navigation.

The project is created to practice front-end web development concepts, including HTML page structure and CSS styling.

## ✨ Features

- Clean and attractive user interface.
- Simple navigation menu.
- Frozen yogurt shop branding.
- Product introduction section.
- Banner image display.
- Footer navigation section.
- External website attribution link.

## 🛠️ Technologies Used

- **HTML5** – For creating the website structure.
- **CSS3** – For styling and designing the webpage.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Shubhammehta707/HTML-project.git
   ```

2. Open the project folder:

   ```bash
   cd HTML-project
   ```

3. Open `fruit.html` in your web browser.

4. Make sure the banner image (`Untitled 2.png`) is available in the project directory.

The main purpose of this project is to improve practical knowledge of HTML and CSS by creating a simple frozen yogurt shop landing page.
